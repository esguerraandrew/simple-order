# Simple Order Receipt

**Author:** Andrew

A Dart program that prints order receipts with an automatic 10% discount for orders of 300 or more.

## Sample output

```
Order for Guest
3 x Adobo rice     255.00
1 x Iced tea        35.00
3 x Turon           75.00
Subtotal           365.00
Discount 10%       -36.50
Total              328.50

Order for Andrew
2 x Adobo rice     170.00
1 x Iced tea        35.00
Subtotal           205.00
Total              205.00
